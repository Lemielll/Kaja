# Pernyataan Idempotency

Operasi unsafe pada kelompok rental dan inspeksi menerapkan empat ketentuan berikut:

1. Header `Idempotency-Key` wajib dikirim pada setiap request yang mengubah state.
2. Header tersebut dibangkitkan oleh client saat user menegaskan intent, lalu digunakan kembali tanpa perubahan pada seluruh retry untuk intent yang sama.
3. Key disimpan selama 24 jam dan dipakai untuk mendeteksi duplikasi request.
4. Jika key yang sama dipakai dengan body yang berbeda, server mengembalikan `409 idempotency-key-reuse`.

## Penerapan pada operasi unsafe

- `POST /rentals`: wajib membawa `Idempotency-Key` untuk menghindari pembuatan kontrak ganda.
- `POST /rentals/{id}/inspections`: wajib membawa `Idempotency-Key` untuk mencegah duplikasi inspeksi pada rental yang sama.
- Jika client mengulang request yang sama dengan key yang sama dan payload yang identik, server dapat mengembalikan hasil yang sama atau response idempotent yang konsisten.
- Jika key dipakai ulang dengan payload berbeda, server menolak karena konflik idempotency.

## Teks header

```yaml
parameters:
  - name: Idempotency-Key
    in: header
    required: true
    schema:
      type: string
      format: uuid
    description: |
      Generated by the client when the user confirms, and reused unchanged for every retry of that same intent. Retained 24 hours. Reuse with a different body returns 409 idempotency-key-reuse.
```
